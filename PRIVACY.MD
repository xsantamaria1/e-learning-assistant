# Política de privacidad — E-Learning Assistant

**Última actualización: 30 de octubre de 2026**

## 1. Finalidad

E-Learning Assistant es una extensión de Google Chrome diseñada para facilitar la navegación en cursos de formación online compatibles mediante la automatización de controles de reproducción y avance.

## 2. Recopilación de datos

E-Learning Assistant no recopila, vende ni transmite datos personales a servidores del desarrollador.

La extensión no solicita nombres, direcciones de correo electrónico, contraseñas ni información de pago.

## 3. Almacenamiento local

La extensión utiliza el almacenamiento de Chrome para conservar su estado de activación y las preferencias necesarias para su funcionamiento.

También puede mantener temporalmente información técnica sobre la actividad de los módulos para gestionar el cierre automático por inactividad.

Esta información permanece en el entorno local del navegador.

## 4. Acceso a sitios web

La extensión funciona exclusivamente en los siguientes dominios:

- fopstraining.airlinewebservices.com
- share.synthesia.io

El acceso se utiliza para identificar controles de reproducción y navegación, ejecutar acciones automatizadas y detectar el estado de los módulos compatibles.

## 5. Compartición de datos

E-Learning Assistant no comercializa ni comparte información personal con anunciantes o terceros.

La extensión interactúa con plataformas de formación de terceros, que pueden disponer de sus propias políticas de privacidad.

## 6. Seguridad

La extensión limita su funcionamiento a los dominios declarados y utiliza las API de Google Chrome necesarias para realizar sus funciones.

## 7. Cambios en esta política

Esta política podrá actualizarse si cambian las funcionalidades de la extensión o sus prácticas de tratamiento de datos.

## 8. Contacto

Para consultas relacionadas con esta política de privacidad, contacta con el desarrollador mediante los datos de contacto publicados en la ficha de Chrome Web Store.
